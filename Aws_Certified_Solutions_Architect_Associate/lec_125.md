## 3️⃣ Schedule Automatic Calls with cron ⏰

### 🎯 The Goal

Call the API **every 15 seconds**.

### 🤔 The Catch

cron's smallest unit is **one minute**. So how do we get 15 seconds? 

> 🧒 **The trick:** Create **four** jobs. All run every minute, but each waits a different number of seconds before calling:
> - Job 1: call immediately → at 0 seconds
> - Job 2: wait 15 seconds, then call
> - Job 3: wait 30 seconds, then call
> - Job 4: wait 45 seconds, then call
>
> Together, that's one call every 15 seconds. 🎯

### 📝 The Steps

```
1️⃣ Run: crontab -e
2️⃣ Press  i  to enter INSERT mode (so you can type)
3️⃣ Type the four lines below
4️⃣ Press Esc, then type  :wq  and press Enter  (save and quit)
```

```
* * * * * curl <YOUR-API-URL>
* * * * * sleep 15 && curl <YOUR-API-URL>
* * * * * sleep 30 && curl <YOUR-API-URL>
* * * * * sleep 45 && curl <YOUR-API-URL>
```

### 🔍 Decoding `* * * * *`

> The five stars mean **"every minute, of every hour, of every day, of every month, on every weekday."** In plain words: **every minute**.

| Part | Meaning |
|---|---|
| `* * * * *` | Run every minute |
| `sleep 15` | Wait 15 seconds first |
| `&&` | "...and then, only after that finishes..." |
| `curl <URL>` | Call the API |

### ⚠️ Pasting Tip

> When you paste into the vi editor, the **first few characters may get lost**. Always press **`i`** first (insert mode), then paste, and check each line looks right before saving. If characters are missing, add them back by hand.

## 4️⃣ Watch the Calls Arrive in X-Ray 👀

```
1️⃣ Wait about a minute (cron needs time to start)
2️⃣ Open X-Ray → Traces → refresh
```

| What You'll See | Meaning |
|---|---|
| 📥 First call arrives after roughly **1–1.5 minutes** | cron kicked in ✅ |
| 📥 More calls every **15 seconds** | The schedule works ✅ |
| 🌐 A **client IP** on each trace | Shows where the call came from |

> 💡 **Tip:** Set the X-Ray time range to just the **last 1 minute** so you only see fresh calls.

## 5️⃣ Repeat on the Private Instance 🔁

### 🌐 What the Client IP Tells Us

After a couple of minutes, you'll see a **new IP address** in X-Ray: the **public IP of the private instance**.

> 🎯 **Key Insight:** The client IP shown in X-Ray is the **public IP the call came from**. Different instances show up as different IPs, so we can tell **which instance** made each call.

```

```

## ❓ Extra Important Question: "Why call the API every 15 seconds instead of just once or twice?"

> 💡 **Answer:** Because we'll be **changing route tables live** and want to see the effect quickly. If we called only once an hour, we'd wait ages to find out whether a change worked. With a call every 15 seconds, we can change a route, then watch X-Ray: if new traces from an instance **stop appearing** within a minute or two, we know that instance has lost internet access. If they **start appearing**, it's connected. It's like a **heartbeat monitor**: you can see the moment the heartbeat stops.
