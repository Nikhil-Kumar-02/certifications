## 2️⃣ HTTP API vs REST API — What's the Real Difference? 🤔

> 💡 **Core Idea:** Both can build REST-style APIs, but they're not the same thing.

```
🛠️ REST API   → "Complete control over the request and response"
⚡ HTTP API   → "Low-latency and cost-effective, with built-in support"
```

> 🎯 **Key Insight:** HTTP API is actually the **newer**, simpler, and more **cost-effective** version — but as of this recording, it doesn't yet support all the features REST API offers. Expect HTTP API's feature set to grow over time.

> 🎓 **For This Demo:** We used **REST API** to explore the full feature set.

---

## 3️⃣ Choosing an Endpoint Type 🌍

When creating the API (named `hello-world-api-gateway`), you choose an endpoint type:

| Endpoint Type | What It Means |
|---|---|
| 🌐 **Regional** | Endpoint served from your specific AWS Region |
| ⚡ **Edge Optimized** | Served via AWS's global **Edge Locations** (200+ locations, vs. ~20 Regions) — powered by **CloudFront** for lower global latency |
| 🔒 **Private** | Accessible only within a private network |

> 🎓 **For This Demo:** We chose **Regional**.

## ❓ Extra Important Question: "Since HTTP API is cheaper and lower-latency, why would anyone still choose REST API for a new project today?"

> 💡 **Answer:** It comes down to which specific features your project actually needs. REST API still offers a richer feature set in areas like **request/response transformation and validation (Models)**, **API keys and detailed usage plans**, **resource policies for fine-grained access control**, **built-in API caching**, and **canary deployments** for gradual rollout. If your use case needs any of these — heavy customization of requests/responses, granular per-client throttling, or safe gradual version rollouts — REST API remains the right choice. If you just need a fast, simple, cost-effective way to front a Lambda function with basic auth, HTTP API is usually the better fit today. Always check AWS's current feature-parity documentation, since HTTP API has been gaining features over time.
